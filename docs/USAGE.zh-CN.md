# Clipori · 基本操作

[← 返回 Clipori](../README.zh-CN.md)


| 操作 | 快捷键 / 入口 |
| --- | --- |
| 显示或收起 | `⇧⌘V`，或点击菜单栏图标 |
| 搜索 | 直接输入；`⌘F` 返回搜索框 |
| 悬停卡片 | 轻微抬升与高亮，不选中、不复制、不粘贴 |
| 选中并复制卡片 | 单击只选中当前卡片，并用它完整替换系统剪贴板内容；面板保持打开 |
| 键盘选择卡片 | `↓` 进入卡片选择，再用 `← →`；按 `⌘C` 复制 |
| 多选 / 连续选择 | `⌘` 点击 / `⇧` 点击，用于归类，不改变剪贴板 |
| 批量归类 | 拖动任一已选卡片到分类标签，或使用右键「移动到分类」 |
| 收录截图 | `⌃⇧⌘4` 将选区复制到系统剪贴板，Clipori 开启记录时自动收录 |
| 预览图片 | 选中卡片后按空格，或右键「预览」 |
| 粘贴到原应用 | 回车或双击卡片 |
| 以纯文本粘贴 | `⇧↩`（仅文字与链接；图片使用普通粘贴） |
| 快速粘贴前 9 条 | `⌘1`～`⌘9`；加 `⇧` 为纯文本 |
| 复制 / 预览 / 打开链接 | 卡片区域 `⌘C` / 空格 / `⌘O` |
| 重命名 | `⌘R` |
| 编辑 / 追加 | `⌘E`，或卡片右键菜单 |
| 新建备忘 | `⌘N` 或右上角 `+` |
| 每日备忘录 | 卡片栏「每日备忘录」，或菜单栏右键菜单 |
| 删除 / 撤销删除 | 卡片区域 Delete / `⌘Z` |
| 切换分类 / 新建 Pinboard | `⌘←`、`⌘→` / `⇧⌘N` |
| 暂停或继续记录 | `⌘T` |
| AI 找回 | 输入问题后 `⌘↩`，或点击 AI 找回 |
| 设置 | `⌘,` 或右上角设置按钮 |

设置 → 快捷键可录制新组合并检测冲突；保存后生效，重启后保留。文字编辑区域保留系统的复制、撤销等操作。暂不支持多选批量粘贴。

直接粘贴需要用户在 macOS 辅助功能设置中授权 Clipori。未授权时仍会复制所选内容，切回目标应用后手动 `⌘V` 即可。快捷键注册失败时会提示，可继续使用菜单栏入口。

图片支持剪贴板中的 PNG、TIFF、JPEG，包括按住 Control 复制到剪贴板的截图；只保存成文件的截图不会自动收录。保留原始像素尺寸与透明度，复制时提供 PNG/TIFF，可回粘到支持图片的应用。编辑图片标题和备注后可以搜索。当前图片仅保存在这台 Mac，暂不含图片文字识别、图片 iCloud 同步；不会向 AI 发送图片像素。超过 128 MB 或 8000 万像素时会提示，避免占用过多资源。

卡片左上角自动按内容类型显示图标（文字、链接、图片或代码），颜色跟随所属分类。分类名称和颜色可在「设置 → 分类」中修改。

在「设置 → 分类」中拖动分类行或左侧手柄，即可调整顺序。记忆栏顶部的分类会同步调整，顺序自动保存在本机；新分类追加在末尾。点击某行的「编辑」，可在原行修改名称、颜色和固定状态，按勾号或回车保存，按叉号或 Esc 取消。下方表单只用于添加新分类。

点击颜色色块打开系统调色板，可自由选色或输入十六进制色值。已有分类选好颜色后需保存该行；新分类在添加时保存颜色。

在「设置 → 数据」点击「清空所有记录…」，核对数量后确认。所有文字、图片、手动备忘、固定记录和固定分类中的记录都会删除，已打开的备忘窗口会关闭；分类、快捷键和 AI 配置保留。清空无法撤销，使用 iCloud 同步时，其他设备上的对应记录也会删除。之后复制的新内容仍会按原设置收录。

## 每日备忘录

从卡片栏「每日备忘录」或菜单栏右键菜单打开。左侧按日期选择今天或往期页面，右侧按「事项 / 子任务」编辑。事项支持备注与链接，子任务可分别勾选；没有子任务的事项可直接勾选完成。子任务输入后按回车继续添加。用拖动手柄或「…」菜单调整顺序，删除后可在底部立即撤销。

点亮事项旁的 pin 后，只要还有未完成的子任务，整件事会连同已完成进度一起延续到次日。全部勾完后，事项仍留在当天页面，次日不再带入；取消 pin 也只停止后续延续，不删除当前内容。未 pin 的事项只留在原日期。

首次打开时创建当天页面；之后窗口所在的应用运行期间会检查跨天，休眠唤醒或再次打开时也会检查。应用关闭期间缺少的日期会在下次打开每日备忘录时补齐，按相同规则延续事项。日期按本机时区计算。

每个日期独立保存内容。今天的勾选不会改变昨天；往期页面也可以补充修改，但不会回写已生成的其他页面。内容自动保存，切换日期和关闭窗口前会保存最新输入，保存失败时保留当前草稿并提示重试。

### AI 辅助生成

先在「设置 → AI」配置服务、模型和 API Key。打开每日备忘录，选择日期后点击「AI 整理」，AI 会根据这一天仍保存在本机的文字、链接剪贴板记录和已有事项生成建议。该入口按需调用，不会在打开页面时自动上传内容。图片、图片备注和普通手动备忘不作为剪贴板资料发送；当前每日备忘录的已有事项会作为去重上下文发送。

建议可以先修改再勾选「加入所选」。相关的新行动可以补充到已有事项，原有标题、手写备注、pin 和勾选状态保留。新事项默认不 pin、不勾选完成。已完成的子任务不会被相同标题的建议重新添加。建议和保存后的事项中可展开「剪贴板来源」，查看经本地核对的原文；引用有效不代表 AI 理解一定准确，采用前可自行调整内容。

重复复制先在本地去重，每次最多读取最新 200 条符合条件的记录，正文总预算 32,000 字符，每条最多 2,400 字符；超出时界面会提示截取范围。已经清理掉的历史剪贴板无法再供 AI 分析，但已保存的每日备忘录及其来源摘录仍保留。AI 失败或取消不会改动备忘录，可以重试或继续手动填写。

卡片右键「添加到每日备忘录」可将标题和文本内容加入今天的新事项。每日备忘录目前为 Mac 本地功能，数据库是数据目录中的 `daily-notes.sqlite`；不受剪贴板保留期限或「清空所有记录」影响，暂不参与 iCloud 同步。
