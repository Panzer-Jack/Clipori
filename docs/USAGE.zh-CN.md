# Clipori · 基本操作

[← 返回 Clipori](../README.zh-CN.md)


| 操作 | 快捷键 / 入口 |
| --- | --- |
| 显示或收起 | `⇧⌘V`，或点击菜单栏图标 |
| 搜索 | 直接输入；`⌘F` 返回搜索框 |
| 悬停卡片 | 轻微抬升与高亮，不选中、不复制、不粘贴 |
| 选中并复制卡片 | 单击只选中当前卡片，并用它完整替换系统剪贴板内容；面板保持打开 |
| 键盘选择卡片 | `↓` 进入卡片选择，再用 `← →`；按 `⌘C` 复制 |
| 多选 / 连续选择 | `⌘` 点击 / `⇧` 点击，用于归类，不改变剪贴板 |
| 批量归类 | 拖动任一已选卡片到分类标签，或使用右键「移动到分类」 |
| 收录截图 | `⌃⇧⌘4` 将选区复制到系统剪贴板，Clipori 开启记录时自动收录 |
| 预览图片 | 选中卡片后按空格，或右键「预览」 |
| 粘贴到原应用 | 回车或双击卡片 |
| 以纯文本粘贴 | `⇧↩`（仅文字与链接；图片使用普通粘贴） |
| 快速粘贴前 9 条 | `⌘1`～`⌘9`；加 `⇧` 为纯文本 |
| 复制 / 预览 / 打开链接 | 卡片区域 `⌘C` / 空格 / `⌘O` |
| 重命名 | `⌘R` |
| 编辑 / 追加 | `⌘E`，或卡片右键菜单 |
| 新建备忘 | `⌘N` 或右上角 `+` |
| 删除 / 撤销删除 | 卡片区域 Delete / `⌘Z` |
| 切换分类 / 新建 Pinboard | `⌘←`、`⌘→` / `⇧⌘N` |
| 暂停或继续记录 | `⌘T` |
| AI 找回 | 输入问题后 `⌘↩`，或点击 AI 找回 |
| 设置 | `⌘,` 或右上角设置按钮 |

设置 → 快捷键可录制新组合并检测冲突；保存后生效，重启后保留。文字编辑区域保留系统的复制、撤销等操作。暂不支持多选批量粘贴。

直接粘贴需要用户在 macOS 辅助功能设置中授权 Clipori。未授权时仍会复制所选内容，切回目标应用后手动 `⌘V` 即可。快捷键注册失败时会提示，可继续使用菜单栏入口。

图片支持剪贴板中的 PNG、TIFF、JPEG，包括按住 Control 复制到剪贴板的截图；只保存成文件的截图不会自动收录。保留原始像素尺寸与透明度，复制时提供 PNG/TIFF，可回粘到支持图片的应用。编辑图片标题和备注后可以搜索。当前图片仅保存在这台 Mac，暂不含图片文字识别、图片 iCloud 同步；不会向 AI 发送图片像素。超过 128 MB 或 8000 万像素时会提示，避免占用过多资源。

卡片左上角自动按内容类型显示图标（文字、链接、图片或代码），颜色跟随所属分类。分类名称和颜色可在「设置 → 分类」中修改。

在「设置 → 分类」中拖动分类行或左侧手柄，即可调整顺序。记忆栏顶部的分类会同步调整，顺序自动保存在本机；新分类追加在末尾。点击某行的「编辑」，可在原行修改名称、颜色和固定状态，按勾号或回车保存，按叉号或 Esc 取消。下方表单只用于添加新分类。

点击颜色色块打开系统调色板，可自由选色或输入十六进制色值。已有分类选好颜色后需保存该行；新分类在添加时保存颜色。
